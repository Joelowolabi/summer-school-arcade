Word Chain Blitz

Goal: first team to 15 chained words.

  1. Each word must start with the last letter of the one before.
  2. Type a word and press Enter to add it.
  3. No repeats, real words only — invalid entries bounce.
  4. Any teammate can grab the next slot; fastest valid wins.
